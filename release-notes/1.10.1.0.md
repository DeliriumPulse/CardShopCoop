# CardShopCoop 1.10.1.0 (community build)

Unofficial continuation of DeliriumPulse's CardShopCoop, maintained at
https://github.com/NotBrendan/CardShopCoop while upstream is inactive.

- A Steam invite accepted while the game is **closed** now joins the host's shop once
  the main menu loads. Before, the lobby was recognised but the join never started.
  (Upstream issue #15.)
- BepInEx **Configuration Manager** no longer causes a "mod set differs" rejection. It
  only draws a local settings window, so one player having it installed is fine.
  Gameplay mods still have to match exactly on both PCs.
- The guest-coin fix from 1.10.0.1 (a 25¢ coin showing as $25 on the host, upstream
  issue #13) is carried forward.
- Everything from the 1.9.2.x and 1.10.0.1 reliability builds: guest item-transfer
  retries and recovery, per-player Steam send queues, shared-wallet reservations,
  stable counter/table identities, and connection-health reports.

## Install

Unzip `CardShopCoop-Custom-1.10.1.0.zip` over the game folder so the DLL lands at
`BepInEx\plugins\CardShopCoop\CardShopCoop.dll`. Remove any other CardShopCoop DLL.
Verify with `CardShopCoop-Custom-1.10.1.0-SHA256SUMS.txt`.

## Honest status

Release build, zero warnings; 378 automated checks pass. Those checks simulate the
game and Steam boundaries — they do **not** replace a two-PC session. The two new
fixes in particular (cold-start invite, Configuration Manager) have not yet been
tried live. Please report what breaks at the fork's issue tracker.

Wire 110. **Both players must run exactly 1.10.1.0.**
