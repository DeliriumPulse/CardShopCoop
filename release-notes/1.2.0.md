# CardShopCoop 1.2.0

Most of this update is [Meepen](https://github.com/meepen)'s work. Thanks for the continued development, fixes, and testing!

- Boxes and furniture stay synchronized through pickups, throws, placement, and joining.
- Register checkout and change catch-up have been improved. Served customers stay visible, and stale register reservations are released.
- Worker screens open more reliably for guests, and card-pack refill options match the host and can be changed.
- Guests can stock newly placed shelves and refill empty labeled boxes with a different product.
- Warehouse rack label removal now updates the other player.
- Fixed an item duplication issue when a guest pulled stock into a box while a customer or another player took stock from the same shelf.

See the [changelog](https://github.com/DeliriumPulse/CardShopCoop/blob/master/CHANGELOG.md#120) for the full list of changes.

Replace any earlier 1.2 development build with this release too. **Both players must update.**
